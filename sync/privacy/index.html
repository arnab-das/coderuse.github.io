Privacy Policy

This policy explains what data CodeRuse Sync accesses, why it accesses it, where that data goes, and how you remove it.

Effective date: 10 September 2026. Last updated: 10 September 2026.

1. Who is responsible

CodeRuse Sync is an individually maintained, non-commercial tool published at https://coderuse.com/sync/ by the operator of coderuse.com. There is no company, no staff and no shared infrastructure behind it. Contact: dasarnab45@gmail.com.

2. What the application is

CodeRuse Sync is a command-line utility that runs entirely on the computer of the person using it. It transfers that person's own files from Microsoft OneDrive into that same person's Google Drive. It has no server component, no hosted database, no analytics backend and no user accounts. Nothing the application processes is transmitted to coderuse.com.

3. Google user data the application accesses

When you authorise CodeRuse Sync, you grant exactly one OAuth scope:

ScopeWhat it allowsWhy it is required
.../auth/drive.file Create files and folders in your Google Drive, and read, update or delete only the files that this application itself created. The application has to write the copied OneDrive files into your Drive, and on later runs it must re-check those same files so that unchanged ones are skipped instead of uploaded again.

Within that scope, the application handles:

  • File content — the bytes of the files being copied.
  • File metadata — names, folder paths, sizes, MIME types, checksums and modification timestamps, used to decide what needs copying.
  • OAuth tokens — the access token and refresh token Google issues so the transfer can continue without re-prompting you.

The application does not request or receive your Google password, your contacts, your Gmail, your calendar, your photos, your location, or any Drive file it did not itself create.

4. How the data is used

Google user data is used for one purpose only: performing the file transfer you asked for, at the moment you asked for it. Specifically, to create and update your copied files in your Drive, and to compare metadata so that work is not repeated.

Google user data is never used for advertising, profiling, personalisation, market research, credit assessment, training or improving any machine learning or AI model, or any purpose unrelated to the transfer.

5. Storage and security

  • OAuth tokens are written to the local rclone configuration file on your own computer (typically ~/.config/rclone/rclone.conf). They are not uploaded anywhere.
  • File contents are streamed between Microsoft's servers, your computer and Google's servers over encrypted HTTPS/TLS connections. Copies are not retained by the application beyond what the operating system may cache during a transfer.
  • Logs written by the tool record file names and transfer results. They are stored locally and are never transmitted.
  • Because everything is local, the security of this data is governed by the security of your own machine and account. You are encouraged to protect the configuration file with appropriate file permissions or rclone's built-in configuration encryption.

6. Sharing and disclosure

No Google user data is sold, rented, traded, or transferred to any third party, human or automated. There are no advertisers, no data brokers, no subprocessors and no analytics vendors involved. The only parties that see the data are you, Microsoft (as the source), and Google (as the destination) — each acting under their own terms.

7. Limited Use disclosure

CodeRuse Sync's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

8. Retention and deletion

  • OAuth tokens are retained on your machine only until you revoke access or delete the configuration file.
  • Copied files remain in your Google Drive under your control; deleting them in Drive deletes them.
  • Because no data reaches the developer, there is nothing held on the developer's side to request deletion of.

How to revoke access

  1. Open Google Account → Third-party apps & services.
  2. Select CodeRuse Sync and choose Remove access.
  3. Delete the local rclone configuration entry, or the whole rclone.conf file, to remove the stored token from your machine.
