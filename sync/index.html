CodeRuse Sync

A personal, self-hosted utility that copies files from Microsoft OneDrive into the account owner's own Google Drive. It runs on the owner's own computer, has no backend server, and is not offered as a service to other people.

What it does

CodeRuse Sync is a thin configuration layer around rclone, an open-source command-line file-transfer program. It is used for a single purpose: performing a one-way transfer of the operator's personal files from a Microsoft OneDrive account into that same person's Google Drive account, so that the files live in one place.

  • Reads files from a Microsoft OneDrive account the operator signs in to.
  • Creates and updates the copies of those files in the operator's Google Drive.
  • Compares file names, sizes and modification times so that unchanged files are skipped on later runs.
  • Writes a local log of what was transferred.

Who it is for

CodeRuse Sync is a single-operator tool. It is not published to an app store, it is not sold, and it does not have user accounts, sign-up, or multi-tenant hosting. The only person who signs in to it is the person running it on their own machine — and that person authorises access to their own Google account only.

How it uses your Google Account

When you run CodeRuse Sync for the first time, it opens Google's standard OAuth consent screen in your browser. You choose whether to grant access. If you agree, Google returns an access token to the program running on your own computer.

Permission requestedWhy it is needed
https://www.googleapis.com/auth/drive.file To create the transferred files and folders in your Google Drive, and to update or verify the files that CodeRuse Sync itself created on a previous run. This permission does not give the tool access to any other file already in your Drive.

Nothing leaves your machine

There is no CodeRuse Sync server. Your Google credentials, your OAuth tokens and your file contents stay on the computer you run the tool on. They are never sent to coderuse.com or to any third party. Your file contents travel only between Microsoft's servers, your computer, and Google's servers.

Revoking access

You can withdraw the tool's access to your Google Account at any time from Google Account → Third-party apps & services. Removing it there immediately invalidates the token stored on your machine. Deleting the local rclone configuration file removes the stored token as well.

Source and technology

File transfer is performed by rclone, which is free software released under the MIT licence. CodeRuse Sync adds only the configuration, scheduling and logging around it. No modified or repackaged copy of rclone is distributed.
